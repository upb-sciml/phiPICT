API Reference

Simulation

phipict.Simulation

FluidGym simulation class based on the PICT PISO solver.

phipict.MHDSimulation

MHD simulation using the inductionless approximation.

phipict.SolverTolerance

A tolerance specified relative to the right-hand side.

phipict.simulation.sgs.append_sgs_viscosity_prep_fn

Register a Hook.PRE callback setting block.viscosity = nu_SGS + nu.

Domain

Classes of the compiled extension phipict._C.

phipict.Domain

phipict.Block

phipict.Boundary

phipict.FixedBoundary

phipict.AdvectionScheme

Meshing

phipict.meshing.Mesh

Structured multi-block mesh.

phipict.meshing.MeshBlock

A structured block of a mesh.

phipict.meshing.BlockMesh

Builds a Mesh from block corners, edges, cells and gradings.

phipict.meshing.Quad

A 2D block of a BlockMesh.

phipict.meshing.Hex

A 3D block of a BlockMesh.

phipict.meshing.Patch

A named group of boundary faces with a condition.

phipict.meshing.FacePatches

The patch of each face of a block; None for faces without one.

phipict.meshing.read_blockmeshdict

Read a blockMeshDict as a Mesh.

phipict.meshing.write_blockmeshdict

Write the blocks of a BlockMesh as a blockMeshDict.

phipict.meshing.read_vtk

Read structured grids as a mesh.

phipict.meshing.shapes

Single blocks from corners, edges, resolution and grading.

phipict.meshing.grading

Cell distributions along a block edge.

phipict.meshing.curves

Shapes of block edges.

phipict.meshing.boundary

Named boundary patches and their conditions.

phipict.meshing.connect

Block connections found from the geometry.

phipict.meshing.quality

Cell quality measures of structured blocks.

phipict.meshing.formats.blockmeshdict

OpenFOAM blockMeshDict files.

phipict.meshing.formats.vtk

Structured grids from VTK files.

Grids and I/O

phipict.io.export.vtk

VTK XML output of meshes and solutions, for ParaView and pyvista.

phipict.io.export.series

Time series of VTK snapshots, as a ParaView .pvd collection.

phipict.io.domain_io

Saving and loading of multi-block domains to/from .json + .npz files.

phipict.grid.shapes

Generation and manipulation of structured grid coordinates.

phipict.grid.helpers

Simulation helper functions for FluidGym using _C.

phipict.solvers.amg

Algebraic-multigrid preconditioning for the Poisson-type solves.

Batching

phipict.batching

Batched environments: B copies of one domain simulated together.
