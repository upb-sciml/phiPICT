phipict.meshing.BlockMesh

class phipict.meshing.BlockMesh(merge_tol: float = 1e-09)[source]

Builds a Mesh from block corners, edges, cells and gradings.

Parameters:

merge_tol (float, optional) – Corners closer than this, relative to the size of the mesh, are merged. Default is 1e-9.
